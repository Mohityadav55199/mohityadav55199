## 📌 Featured Projects

### 📄 Production RAG Agent: Document Intelligence Platform
`Python` `FastAPI` `LangGraph` `Qdrant` `PostgreSQL` `Next.js 16` · [Code](https://github.com/Mohityadav55199/Production-RAG-Agent) · [Live](https://productionragagent.vercel.app/)
- RAG over **9 document types** (with OCR) and whole GitHub repos; cited answers streamed over SSE with a Groq → Gemini → Claude fallback
- Hybrid search, reranking and query rewriting: **Hit@1 86.7% → 90%**, follow-up **MRR 0.60 → 0.88**, **97.4% LLM-judged faithfulness** on 60 questions
- **6-agent LangGraph** resume tailor with a grounding check that blocks invented claims and LaTeX PDF output
- **398 tests at 80% coverage**, 6 CI jobs, crash-safe Postgres ingestion queue (`FOR UPDATE SKIP LOCKED`)

### 🎟️ EventSphere: Real-Time Event Ticketing Platform
`React` `Redux Toolkit` `Node.js` `MongoDB` `Redis` `Socket.IO` `Stripe` · [Code](https://github.com/Mohityadav55199/EventSphere) · [Live](https://event-sphere-lemon-nu.vercel.app)
- Double-booking-proof seats with Redis holds, atomic MongoDB updates and a unique index: **300 concurrent users on 30 seats → exactly 30 sold**
- **38 REST APIs**, **15 Socket.IO events**, 3 roles, JWT refresh-token rotation, HMAC-signed QR check-in
- Stripe + Razorpay with server-side pricing and idempotent, signature-verified webhooks; **69 tests** in CI
- **10+ MongoDB indexes** cut "my bookings" scans from **150,000 → ~70 documents (~75× faster)**

### 🛒 NovaCart: Multi-Vendor E-Commerce (Mobile + Web + API)
`React Native` `Expo` `TypeScript` `React` `Node.js` `MongoDB` `Stripe Connect` · [Code](https://github.com/Mohityadav55199/NovaCart-eccommerce-react-native-) · [Live](https://nova-cart-eccommerce-react-native.vercel.app/)
- **3 apps (~9K lines)**: Expo shopping app (Android APK via EAS), React vendor/admin dashboard, Express API with **40+ endpoints**
- Orders created only from Stripe's signed webhook (one order per payment) and atomic stock reservation against overselling
- **Stripe Connect** vendor payouts with a 72-hour hold, configurable fee and protection against double payouts
- **4 roles, 12 permissions**, second-admin approval for large refunds, audit log; **34 tests** across Node 20 & 22

### 🤖 AgentSphere: Multi-Agent AI Collaboration Platform
`Next.js 16` `TypeScript` `LangGraph.js` `MCP` `PostgreSQL` `Prisma` · [Code](https://github.com/Mohityadav55199/AgentSphere) · [Live](https://agent-sphere-self.vercel.app)
- **5-agent council** (Supervisor, Researcher, Developer, Analyst, Auditor) across **4 LLM providers** with automatic fallback
- MCP tools (stdio, HTTP, OAuth; 6 presets) with **human-in-the-loop** allow / deny / edit-arguments approval
- Thread isolation, HMAC-signed sessions, rate limits, SSRF guards (**20/20 live security checks**); **139 → 0 vulnerabilities**, **81 tests**
